# DeskOps – Phase 1 Documentation

This folder contains the team's working documentation for DeskOps Phase 1.

## Documents
1. [Project and PRD Overview](01-project-and-prd-overview.md) – what we are building and what the PRD means.
2. [Roles and Permissions](02-roles-and-permissions.md) – simple role definitions and a **proposed** permission matrix.
3. [Dental Clinic Client Rule](03-dental-clinic-client-rule.md) – the team-specific rule that must be implemented and tested.

## Important
- The uploaded LogicVeda PRD is the source of truth for Phase 1 requirements.
- The PRD requires a role-by-action permission matrix (NFR-02), but does not define the exact Admin/Staff role permissions. The matrix in this folder is a team proposal and must be reviewed and agreed by the team/mentor.
- Keep this folder updated as design decisions are approved. Record significant architectural decisions in `docs/adr/`.
